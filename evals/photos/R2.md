# R2 — Lists from geometry

Plan: [`docs/plans/photo-to-model-recovery.md`](../../docs/plans/photo-to-model-recovery.md)

**Objective:** Cut/material lists follow from solids, not typed numbers beside them.

## Delivered

| Piece | Path |
| --- | --- |
| `part(id, solid, …)` | `furniture_cad/derive.py` |
| Estimate flags | Measured / Estimated / Guessed / Shaped from blank on `PartRecord` + cut list |
| Consistency | Volume sum vs assembly + AABB overlaps in `lists()` |
| Build namespace | `part` exported next to `PartRecord` / `Box` |
| Tests | `tests/test_r2_derive.py` — fixture sizes within 5%, exact qty |

## Gate

- [x] Derived dims match typed oracle fixture within **5%** (sorted T/W/L) and **exact qty**
- [x] No new list path depends on hand-entered blank size when `part()` is used
- [ ] Full oracle set (`chair_04`, `chair_02`, `case_01`) rewritten onto `part()` — follow-up as scripts migrate

## Usage

```python

parts = [leg, ...]
```
