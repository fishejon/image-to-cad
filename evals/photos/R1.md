## Commands

```bash
cd lab/furniture_cad && source .venv/bin/activate
pytest -q tests/test_r1_geom_check.py

# Offline render/check after oracle build:
python -m furniture_cad run --freeze-set case_01 --work out/oracle
python -m furniture_cad run --work out/oracle/case_01 --call check '{"targets_mm":{"w":1219,"d":305,"h":1803}}'
python -m furniture_cad run --work out/oracle/case_01 --call render '{"views":["front","side","iso"]}'

# Live blind-style (needs ANTHROPIC_API_KEY):
python -m furniture_cad run --work out/r1/case_01 \
  --photo ../../evals/photos/cases/case_01.jpg \
  --known-mm 1219 305 1803 \
  --prompt "Build this bookshelf to the known overall size. Material: walnut." \
  --max-spend 2
```

## Gate

Checks agree with unit tests on known solids; each live run saves project (script, STL, renders, check/compare) under `--work`.
