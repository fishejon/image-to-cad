# Chair / stool photo pack (local)

Drop **your** photos here. Nothing uploads to the server.

## Per photo

| File | Purpose |
| --- | --- |
| `chair_01.jpg` (or `.png` / `.webp`) | Reference photo |
| `chair_01.json` | Hand params for `four_leg_chair` or `stool` |

Start from [`_params.template.json`](_params.template.json).

## Score

Add a row to [`SCORE.md`](SCORE.md) after each compile.

## Privacy

Keep this folder local if photos are private; do not commit images you do not want in git. Params JSON without photos is fine to commit.
